# Plan 04.1 — Spendly Design Tokens & Visual Elevation

**Status:** Pass 1 (tokens) implemented. Pass 2 (layout/component enhancements)
still deferred — see §8 for the exact remaining items.
**Scope:** `templates/landing.html`, `templates/profile.html`,
`templates/register.html` (+ `templates/base.html`, `static/css/style.css` as
their shared surface).
**Goal:** make the UI feel premium and intentional without new dependencies, JS,
or a heavier page.

---

## 1. Read of the brief + audit

Spendly is a **student expense tracker for rupees**: fast daily logging, a
monthly view, campus-scale numbers. The design should feel like a well-kept
ledger — exact, calm, quietly confident — not a generic SaaS dashboard.

What currently makes it read as generic:

| # | Symptom | Where |
|---|---|---|
| A1 | Warm cream paper + high-contrast serif + warm accent = the default AI "editorial fintech" cluster | `--paper #f7f6f3`, `DM Serif Display`, `--accent-2 #c17f24` |
| A2 | Three identical `.stat-card`s in a row, twice (hero mock + profile) — the SaaS-card kit | `landing.html` hero mock, `profile.html` |
| A3 | Three identical rounded `.feature-card`s on a tinted band | `landing.html` features |
| A4 | Three different greens, one of them an untokenised hex | `--accent #1a472a`, `.hero-title-accent #0f9d68`, `.window-dot-green #7ed6b1` |
| A5 | ALL-CAPS tracked-out table headers and a `·`-joined meta pill | `profile.html` thead, `landing.html` hero badge |
| A6 | Faint text fails contrast: `--ink-faint #a0a0a0` on paper = **2.42:1** | "Member since", stat notes, placeholders |
| A7 | Seven unrelated saturated category hues (amber, blue, purple, pink, brown, green, grey) | `--cat-*`, breakdown bars |
| A8 | Ad-hoc spacing: `1.75rem`, `3.5rem`, `4.5rem`, `5rem`, `1.25rem` in the same page | `style.css` throughout |
| A9 | Page titles serif but the landing H1 is sans — the two pages do not share a typographic voice | `profile.html`, `register.html` vs `landing.html` |
| A10 | Inputs sit on `--paper` inside a white card, so fields look muddy and the card looks like a form template | `.form-input` |

---

## 2. Direction — "Quiet ledger"

One idea holds the whole product: **a page is a ledger sheet, not a dashboard**.
Hairline rules, tabular numbers, a single dark total, and colour used only where
it means something (a category, an error, focus). Spend the boldness in exactly
two places: the **money total** (large serif figure) and the **single dark footer
band**. Everything else stays quiet.

This is deliberately not the default: cool paper instead of cream, one viridian
accent instead of a multi-colour chart, serif reserved for figures and titles
instead of every heading, and layout by rules rather than by a grid of cards.

# Pass 1 — Token system

All names already exist in `:root`; the proposal **keeps the variable names** and
changes values, plus adds a small number of new tokens. That means the migration
is mostly cosmetic and no template class renames are needed.

## 3.1 Colour — 5 named bases

| Token | Value | Role |
|---|---|---|
| `--paper` | `#F4F5F0` | page background, cool green-grey paper (no cream) |
| `--paper-card` | `#FFFFFF` | cards, table surface |
| `--paper-sunk` | `#EDEFE8` | row hover, bar tracks, quiet fills |
| `--ink` | `#141915` | primary text, primary buttons, footer |
| `--accent` | `#0F5C44` | viridian: links, focus, active state, the one green |

Derived text + line tokens:

| Token | Value | Role | Contrast |
|---|---|---|---|
| `--ink-soft` | `#2F3A32` | body copy | 10.8:1 on `--paper` |
| `--ink-muted` | `#58635B` | secondary text, table headers | 5.7:1 |
| `--ink-faint` | `#67736B` | 12–13px meta only | 4.5:1 (was 2.4:1) |
| `--border` | `#DDE0D8` | hairlines, card borders | decorative |
| `--border-soft` | `#E9EBE4` | table row rules | decorative |
| `--border-strong` | `#C9CEC3` | input hover | decorative |
| `--accent-strong` | `#0A4231` | accent hover/pressed | 11.4:1 on white |
| `--accent-light` | `#E3EFE9` | avatar, selected state | accent 6.8:1 on it |
| `--accent-2` | `#94601D` | ochre, top-category emphasis only | 4.9:1 on paper |
| `--accent-2-light` | `#F7EEDE` | ochre tint | — |
| `--danger` | `#A93226` | errors | 6.6:1 on white |
| `--danger-light` | `#FAE9E6` | error surface | danger 5.6:1 on it |

Rules:

- Five hues total (viridian, ochre, violet, steel, rose) + neutral for data.
  No gradients, no tinted near-black, no second green.
- `--accent` is for **interaction**; `--accent-2` is for **one data highlight**
  (the biggest category). They never compete in the same block.
- Every text colour clears WCAG AA at its intended size; `--ink-faint` is the
  lowest allowed and only at ≥12px.

Category palette — 4 hues + neutral, mapped by meaning, not per category:

| Token | Value | Categories |
|---|---|---|
| `--cat-food` | `#94601D` | Food, Shopping |
| `--cat-entertainment` | `#6A5AA8` | Entertainment, Bills |
| `--cat-health` | `#A6556F` | Health |
| `--cat-transport` | `#2E6E8E` | Transport |
| `--cat-other` | `#68746C` | Other |

Duplicated hues land on non-adjacent rows in the default descending order
(Bills 1 / Entertainment 5, Shopping 2 / Food 4), so the breakdown still reads
as seven distinct bars — with half the colour noise.

## 3.2 Type — two families, two jobs

| Role | Family | Why |
|---|---|---|
| Display: wordmark, page titles, hero headline, the money figure | **Fraunces** (400/500, opsz) | a soft, slightly printed serif — ledger character, not a luxury-magazine serif |
| Everything else: UI, body, tables, labels, buttons | **DM Sans** (400/500/600) | already loaded, excellent at 12–16px, tabular figures |

Load: replace the `DM Serif Display` family in the existing Google Fonts URL with
`Fraunces:opsz,wght@9..144,400;9..144,500` — same number of requests, no new
dependency. DM Sans stays.

Rules:

- Serif appears **only** at display sizes (≥28px). Never serif for card titles or
  labels — that is what made the auth pages feel templated.
- One accent per headline **at most**. Colour spans inside the H1 are removed
  (see L1); hierarchy comes from the serif/sans mix and line breaks.
- All money, counts, and dates use `font-variant-numeric: tabular-nums`.
- No ALL-CAPS labels. No monospace face. No letter-spaced eyebrow text.

Scale (root 16px):

| Token | Size / line-height | Use |
|---|---|---|
| `--text-xs` | 12px / 1.35 | table headers, meta, badges |
| `--text-sm` | 13px / 1.45 | labels, helper text, stat labels |
| `--text-base` | 16px / 1.6 | body, table cells |
| `--text-md` | 16px / 1.4, 600 | card titles (sans) |
| `--text-lg` | 20px / 1.35 | section headings (sans, 600) |
| `--text-xl` | 28px / 1.2, serif | page titles (mobile 24px) |
| `--text-2xl` | `clamp(36px, 5vw, 56px)` / 1.08, serif | landing H1 |
| `--text-total` | 44px / 1, serif | profile money figure |

Tracking: display `-0.02em`, hero `-0.03em`, body `0`, small `0.01em`.
Weights: 400 body, 500 UI/labels/buttons, 600 headings. Nothing heavier.

## 3.3 Spacing — one 4px scale, three rhythms

```
--space-1  .25rem (4)     --space-5  1.5rem (24)
--space-2  .5rem  (8)     --space-6  2rem   (32)
--space-3  .75rem (12)    --space-7  3rem   (48)
--space-4  1rem   (16)    --space-8  4.5rem (72)
```

- Page section padding: `--space-8` desktop, `--space-7` at ≤600px.
- Card padding: `--space-5` (was 1.75rem/2rem inconsistently).
- Stack gap inside cards: `--space-4`; between page blocks: `--space-5`.
- Rule: if a value is not on this scale it does not ship. This alone removes
  most of the "hand-assembled" feel.

## 3.4 Shape, borders, elevation

```
--radius-sm  6px    inputs, buttons
--radius-md  10px   cards, table surface
--radius-lg  14px   user strip, hero mock
--radius-full 999px badges/pills only
```

- **No box-shadows.** Hierarchy comes from `--paper` → `--paper-card` →
  hairline border. One exception: the focus ring.
- Every interactive element gets the same focus treatment:
  `outline: 2px solid var(--accent); outline-offset: 2px;`
  (`:focus-visible` only).

## 3.5 Motion

```
--ease: cubic-bezier(.2, .6, .2, 1);
--dur-1: 120ms;   --dur-2: 180ms;
```

Only hover/focus transitions and the existing modal. No entrance animations, no
per-card lifts. `@media (prefers-reduced-motion: reduce)` disables transitions.

## 3.6 Layout & alignment

- `--container: 1120px` (down from 1200), `--container-narrow: 960px` for the
  profile, page gutter `2rem` / `1.25rem` mobile.
- Everything left-aligned, single reading column. Auth is the one centred block —
  and even there the heading is left-aligned inside the card (A10 fix).
- Profile symmetry: user strip, summary strip, and the two-column row all share
  the same width and the same 24px gap.

## 4. Review against the brief (self-critique)

Draft 1 of this plan kept cream paper, used the serif on every heading, and
introduced a monospace face for amounts — i.e. it walked straight into tells
#1, #4 and #5. Revised and why:

1. **Paper warmed → cooled.** Cream + serif + ochre is the default cluster; a
   green-grey paper with a viridian accent reads as money/ledger instead.
2. **Serif demoted.** Serif is now a display-only voice for titles and the money
   figure; card titles and labels are DM Sans. Removes the "editorial template"
   rhythm that every page currently shares.
3. **No monospace.** Tabular DM Sans keeps the numeric character without the
   generated-dashboard tell.
4. **Chart colour reduced 7 → 5.** A restrained breakdown where colour encodes
   a family, and the label carries the exact category.
5. **One memorable moment, not six.** The profile total and the footer band are
   the only loud elements; cards lose their shadows and identical radii.
6. **Removed accessories.** Window dots, the `·` meta pill, the coloured word in
   the H1, and the third green all go (Chanel rule).

## 5. Guardrails

- **No new dependencies**, no JS, no icon library, no dark mode, no motion library.
- Keep the existing `:root` variable names so templates and class names don't churn.
- `landing.html`'s inline modal CSS stays where it is (AGENTS.md rule); only the
  tokens it consumes change.
- WCAG AA at every size; focus ring visible on paper and card; `prefers-reduced-motion`
  respected.
- No page grows in height by more than ~10%. No horizontal overflow at 375px.
- Copy stays plain, sentence case, active voice ("Create account", "Sign out").
- Do not redesign `/expenses/...` or terms/privacy in this pass.

## 6. Execution order

1. **Tokens** — `:root` values, type scale, spacing, radius, focus ring (no
   layout change). Verify contrast and that nothing shifts.
2. **Base** — fonts URL (Fraunces), nav height/radius, footer band, flash.
3. **Auth** — A1–A3, then screenshot login + register at 375/1280.
4. **Profile** — P1–P4, then screenshot with the demo account.
5. **Landing** — L1–L4, re-check the modal still opens and the video resets.
6. **Verification** — `ui-verify`: 375/768/1280, keyboard tab order, contrast spot
   checks (`--ink-faint`, table headers, badge text), console clean, no new
   network requests beyond the font swap.

| Risk | Mitigation |

| Cooler paper + viridian flattens the landing's warmth | Keep the footer as the single dark anchor and the ochre category accent for warmth; review at 1280 before/after. |
